Brivo access normally lives behind a mobile app. OpenBrivo provides an inspectable desktop CLI for authorized Allegion and Schlage XE360 access—with no hosted backend and no telemetry.

From account to lock, transparently.

The full workflow runs from readable Python code on your own computer.

01

Provision once

Sign in with your authorized Mobile Pass account and securely retrieve your XE360 credential.

02

Discover nearby

Use the native Bluetooth stack to identify compatible readers within range.

03

Unlock locally

Establish the encrypted Sapphire session and present the cached credential over BLE.

No OpenBrivo cloud.

Cloud access is used only for first-time provisioning and explicit credential refreshes. Routine unlocks happen directly between your computer and the reader.

Start locally.

Clone the repository, install the platform-specific dependencies, and launch the guided flow. Full setup and troubleshooting details live in the README.

git clone git@github.com:LuD1161/openbrivo.git
cd openbrivo
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python openbrivo.py
Authorized use only. Use OpenBrivo only with accounts and locks you own or are explicitly permitted to access.
